# WUTNet v1.4.0

Windows 正式版，基于用户提供的 `whut-net-v1.4.0-fixed.ps1` 和开发日志收束；Android 同步升级为 1.4.0，仍为实验版。

## Windows

- 默认 `run`：已联网直接退出；已注册 WHUT 网络正常认证；新网络先验证协议，再请求一次明确的 Trust & Connect 确认。
- `trust-current -Label "WHUT-DORM"` 显式追加网络；`setup -AddNetwork` 兼容保留。WHUT-WLAN 与 WHUT-DORM 可同时登记，重复登记不复制条目、不改密码。
- `networks` 显示 ID、标签、物理指纹和登记/更新时记录的时间；`remove-network -NetworkId <id>` 删除单项。修复表格被 dispatcher 吞掉的问题，`-Json` 输出可直接解析。
- v2 单指纹配置自动原子迁移为 v3 `trustedNetworks[]`；v1.3.2 的 v3 条目自动补齐管理 ID/标签。账号和 DPAPI 密文保持不变。普通 setup 也保留旧注册。
- 自动模式仅接受完整匹配的前缀、网关、WHUT host 和接口类型；SSID/Profile Name/接口别名均不自动赋予信任。每次认证仍验证 WHUT bootstrap、config、CSRF、status，并在解密前重查物理网络。
- 发布整合保留 v1.3.2 的原子保存、严格 bootstrap IP/原始重定向路径、协议错误和 config.js 注释/大小写歧义检查。提供的现场修正版原件保留在本地 devlog；发布文件包含上述回归修正，并非原件字节副本。

## Android

- 版本 1.4.0 / versionCode 2，动态 `/api/r/<nasId>` bootstrap、多探针发现、同一 Cookie 会话和注释安全的 config 解析。
- 多个物理 Wi-Fi 指纹需在协议验证后逐个点击 Trust and connect 注册；系统自动入口只使用已注册网络，不读取 SSID。
- 保留 Wi-Fi Network 绑定、代理绕过、Keystore 存储及状态/联网双重复核；失败不回退到蜂窝网络。
- 发布 `wutnet-android-v1.4.0-debug.apk`，为可安装的开发签名测试包，不是生产签名发行包。不同签名的旧包需要卸载重装，凭据和信任列表会随之删除。

## 验证与边界

开发日志记录了 Windows 修正版列出旧指纹、显式追加 WHUT-DORM、保留两项注册和默认模式认证成功。最终整合文件通过离线回归；不将这些测试描述为一次新的现场认证。Android 已运行 JVM 测试、Lint 和 APK 构建，真实设备上的 WHUT 认证仍待验证。详细证据见 [现场记录](../FIELD_VALIDATION.md) 和 [Android 测试清单](../android-testing.md)。

## 下载与升级

Release 包含内容相同的 `whut-net-v1.4.0-fixed.ps1` / `whut-net.ps1`、Android debug APK 和 `SHA256SUMS.txt`。按校验清单核验文件。保留脚本固定位置；若任务原先指向其他路径，运行新脚本的 `install` 更新计划任务。

```powershell
.\whut-net-v1.4.0-fixed.ps1 networks
.\whut-net-v1.4.0-fixed.ps1 trust-current -Label "WHUT-DORM"
.\whut-net-v1.4.0-fixed.ps1
.\whut-net-v1.4.0-fixed.ps1 networks -Json
```

WHUT 当前使用 HTTP；DPAPI/Keystore 仅保护本地存储，物理和协议指纹不构成密码学服务器身份验证。
